# 🔐 Password Generator (GUI)

A simple **Password Generator application built with Python and Tkinter**.
This program generates a random password based on the length provided by the user.

The application uses Python's **random** and **string** modules to create secure passwords containing letters, numbers, and special characters.

---

## ✨ Features

* Generate random passwords
* User-defined password length
* Graphical User Interface using **Tkinter**
* Uses **letters, digits, and symbols** for stronger passwords
* Simple and beginner-friendly implementation

---

## 🛠️ Technologies Used

* **Python**
* **Tkinter** (for GUI)
* **random module**
* **string module**

---

## ▶️ How to Run

1. Make sure Python is installed on your system.

2. Download or clone this repository.

3. Run the Python file:

```
python password_generator.py
```

---

## 🖥️ How It Works

1. The user enters the **desired password length**.
2. Click the **Generate Password** button.
3. The generated password is displayed on the screen.

---

## 📌 Example Output

```
Password Length: 10

Generated Password:
aK9#tP2!Lm
```
